# Images Placeholder

This folder should contain the following images:

## Required Images:

1. **logo.png** - Company logo (recommended: 200x80px)
   - Should be transparent background
   - Used in navigation bar

2. **hero-bg.jpg** - Hero section background (recommended: 1920x1080px)
   - High quality image of playing cards
   - Can be a gradient if no image is available

3. **product-cards.jpg** - Card games product image (recommended: 800x600px)
   - Photo of traditional card games

4. **product-quiz.jpg** - Quiz games product image (recommended: 800x600px)
   - Photo of quiz card games

5. **product-custom.jpg** - Custom cards image (recommended: 800x600px)
   - Photo showcasing custom designed cards

6. **about-company.jpg** - Company/factory image (recommended: 1200x800px)
   - Photo of manufacturing or team

7. **eu-logo.png** - European Union logo (if using EU funding)
   - Official EU logo with proper usage rights

## Optional Images:

8. **favicon.ico** - Browser tab icon (16x16px, 32x32px)
9. **og-image.jpg** - Social media share image (1200x630px)
10. **testimonial-1.jpg** through **testimonial-3.jpg** - Customer photos

## Image Guidelines:

- **Format**: JPG for photos, PNG for logos/icons
- **Optimization**: Compress images before uploading (use tinypng.com or similar)
- **Quality**: High resolution but optimized for web
- **Naming**: Use lowercase, hyphens instead of spaces
- **Alt Text**: Always add descriptive alt text in HTML

## Current Status:

## How to Add Images:

1. Place images in this folder: `assets/images/`
2. Update image paths in `index.html`:
   ```html
   <img src="assets/images/your-image.jpg" alt="Description">
   ```
